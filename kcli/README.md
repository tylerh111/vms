Notes:

* `arch` downloads a third-party, BIOS-only image from linuximages.de; for UEFI, use the official image instead.
* The `freebsd*`, `netbsd*`, `openbsd*` and `dragonflybsd*` aliases come from the community bsd-cloud-image.org mirror, not from the projects themselves.
* Known broken alias URLs in kcli: `ubuntu2504` points at the `24.04/` directory, and the BSD aliases all point under `.../images/dragonflybsd/...`.
* Images without an alias (or official replacements) can be fetched with `kcli download image <name> -u <url>`, or by setting `image: <url>` in a profile.
